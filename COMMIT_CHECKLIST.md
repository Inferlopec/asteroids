# Commit Checklist

Перед каждым коммитом проверь:

## 1. Ручное тестирование
- [ ] Запусти игру: `python main.py`
- [ ] Протестируй новую функциональность
- [ ] Проверь, что старые функции не сломались
- [ ] Проверь краевые случаи (game over, respawn, пауза и т.д.)
- [ ] **Подожди фидбек от пользователя** — подтверди, что всё работает

## 2. Автоматическая проверка
- [ ] Проверь синтаксис: `python -m py_compile <файлы>`
- [ ] Проверь импорт: `python -c "import main"`
- [ ] Запусти с dummy driver: `SDL_VIDEODRIVER=dummy timeout 5 python main.py`
- [ ] **Проверь вывод в консоли** — нет ли ошибок/предупреждений

## 3. Проверка кода
- [ ] Прочитай diff: `git diff`
- [ ] Убедись, что изменения соответствуют задаче
- [ ] Проверь, что не осталось отладочных print'ов
- [ ] Проверь, что нет неиспользуемых импортов/переменных

## 4. Git
- [ ] Проверь status: `git status`
- [ ] Убедись, что коммитятся только нужные файлы
- [ ] Напиши осмысленное сообщение коммита
- [ ] Сделай коммит

## 5. После коммита
- [ ] Запусти игру ещё раз (sanity check)
- [ ] Обнови README.md (если нужно)
